The filter chain

The live frequency response of the chain at the current slider positions. This is read back out of the filters themselves, so it is the response of what actually processes the audio — not a drawing of the sliders.

What each band does
BandTypeCentre / cornerQRange

Shelves at the extremes so the very bottom and top of the spectrum are lifted as a whole; bells in between, each Q derived from that band's width in octaves so the bells tile the spectrum evenly instead of leaving holes.

Spectrum

Welch-averaged FFT magnitude, 1/12-octave smoothed, before and after the chain. Averaging overlapping windows rather than taking one giant FFT is what makes the EQ's effect readable instead of buried in bin noise.

Waveform

Min/max envelope of each bucket, so transients survive the downsampling. The processed lane includes the headroom trim, so it shows what you actually hear.

DSP runs in the browser on Web Audio BiquadFilterNodes, which implement the same Audio EQ Cookbook formulas as the Python eqcore package in this repository — the shelves' default slope S = 1 is exactly the Q = 0.707 that version passes. Analysis (Welch spectrum, fractional-octave smoothing, envelopes) is ported in dsp.js.
